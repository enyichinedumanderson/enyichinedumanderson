# 👋 About Me


Hi, I'm **Enyi Chinedum**, a **Software Developer and DevOps/Cloud Enthusiast**, passionate about building practical software and solving real-world problems through technology.

My experience spans **frontend and backend development**, working with technologies such as **HTML, CSS, JavaScript, TypeScript, React, Next.js, Tailwind CSS, Python, and Django**. I also work with databases and services including **PostgreSQL, MongoDB, and Firebase**.

I'm currently expanding my knowledge in **DevOps and Cloud Engineering**, exploring containerization, CI/CD pipelines, infrastructure automation, cloud platforms, and application deployment. I'm gaining practical experience with tools such as **Git, GitHub, and Docker**.

I'm also building **LoomWing**, a fashion-tech platform aimed at connecting customers with fashion designers and tailors, making it easier to discover designs, request custom outfits, and manage the custom-fashion experience.

Beyond writing code, I enjoy exploring emerging technologies, experimenting with new tools, and documenting what I learn through hands-on projects and technical writing.

- 💻 **Software Development** — Building modern web applications and exploring full-stack solutions using React, Next.js, TypeScript, Python, and Django.

- ☁️ **DevOps & Cloud Engineering** — Developing practical skills in containerization, CI/CD, cloud infrastructure, automation, and deployment.
